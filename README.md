# Consumption_Cost_Analysis

This project explores electricity consumption and associated costs across five boroughs of New York City using visual analytics and regression modeling techniques. The aim is to uncover borough-specific consumption patterns, vendor revenues, and potential predictors of electricity usage through visual and statistical analysis.
